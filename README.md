Palm Bay Heat is an original open-world crime game set in the sun-soaked coastal city of Palm Bay: five districts, traffic and crowds, cars to steal and drive, a five-star wanted system, a five-mission story, combat, a HUD with minimap, a day cycle, synthesized sound and a save.

## Run it

```sh
node serve.ts
```
